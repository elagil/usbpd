# USB PD library and examples

- [Library](./usbpd/)
- [Examples](./examples/)
- [USB PD specification](./USB_PD_R3_2%20V1.1%202024-10.pdf)

The library implements the USB PD protocol and policy engine layers (PD 3.2, SPR + EPR, sink/source/DRP).
USB Type-C hardware management (CC-line role detection, VBUS/VCONN control, and FRS signal detection) is out of scope.
